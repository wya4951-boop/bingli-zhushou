# 日常病程成稿与审核

## 依据与使用边界

参考丁香园《【规培】病程记录书写内容规范（附件资料可下载）》中日常病程部分的结构，2026-10-31读取：https://www.dxy.cn/bbs/newweb/pc/post/51063399 。它是教学帖子，不是国家规范；不复制其病例、药物方案、检验单位或人员机构信息。

国家依据为《病历书写基本规范》（卫医政发〔2010〕11号）第二十二条：https://www.nhc.gov.cn/wjw/gfxwj/201002/79d42b9c8b3f47ee91000d31de116784.shtml 。正式应用还需符合所在医院当前模板与制度。帖子中按护理级别替代病情分级、以检查价格划定特殊检查、所有输血患者固定护理级别等表述，不作为通用规则。

## 从资料到正文

目标是资料充分时交付可以直接供医生审核的连贯正文，而不是要求医生重新组织聊天摘要。先按每个当前问题归并证据，再把已有评估、处理及结果关联起来。不得为追求完整而创造缺失事实；缺少关键评估或处置时，输出待补充草稿，不能标记为完整成稿。

内部逐项核对，正文不必机械分成十个小标题：

- 病情：主要症状和体征较此前的改变，比较对象有明确日期且为同一患者。生命体征、一般情况、出入量采用已提供的当日资料及统计范围。
- 检查：重要结果保留检查日期、数值和单位；把负责医生已有的临床解释与后续处置接在相应结果之后。复查目的、持续监测理由有记录才写。未回报与未检查分开，不把异常数值自动转成诊断。
- 评估：组织已有诊断依据、当前问题与综合判断，保留不确定程度。诊断补充或修正应标明记录中实际作出判断的医师及依据；无判断时在正文外请求补充，不从示例搬入鉴别诊断。
- 治疗：写清新增、调整、停用或继续的具体项目，关联已记录的理由及反应；处置后数值变化不自动等同疗效或因果。只有“继续原方案”而无细节时不自行补全药物。
- 输血：有本次输血时核对指征/目的、成分、血型、数量、执行时段、过程观察、反应及输后评价；分别识别备血、医嘱、开始、完成。没有过程记录不能写“顺利、无反应”，没有复查不能编造输后指标。日常病程摘要不替代院内要求的专门输血记录。
- 查房、会诊、沟通：仅纳入实际发生的意见及其执行状态。沟通对象、告知事项、对方意见和签署状态分别有证据才写；不把未回复写成理解同意。相关文书名称或时间仅在来源明确时引用。
- 后续：明确已有复查、观察、治疗计划及待回报事项；若涉及出院未回报的重要检查，整理已有结果查询与后续安排，缺失则列待补充，不生成联系电话或承诺。

## 交付版式

逐床分为“病程正文”和仅在有缺项时出现的“待补充／核实”。资料来源、草稿提示和模型分析均在正文之外，避免复制入病历时夹带编辑说明。标题中的床号、科室用于文件索引；院内正文遵循院内模板。

正文首行采用用户提供的真实记录时间，另起行写内容；不能拿消息发送时间、模型生成时间代替实际记录时间。仅知日期时保留日期，把缺少时分列于正文外，不默认09:00、不倒签。医师签名由本人在正式系统完成，不代签、不生成姓名占位符。

抽象组织顺序（供生成时参考，不作为含空格占位符的交付模板）：

记录时间 → 当前症状及变化 → 当日客观资料 → 已确认的评估及依据 → 处理、理由、反应 → 明确后续计划与实际沟通。

正文可分为病情与客观资料、分析与诊疗两段；复杂多问题病例允许增加段落，不能为限制篇幅遗漏关键问题。只有当前确有查房事实时才以查房开头；仅有护理摘要时准确保留观察来源。正常项目应是当日已核实的事实，不能套用全套正常查体。

## 成稿门槛

### 先写病程，再核查来源

- 正文采用临床问题驱动的叙述，不按消息发送顺序逐条改写。将同一问题的症状、客观变化、已有判断、处置与转归写在一起；把请示、催单、再次确认、回复“收到”、要求汇总等沟通流程移出正文。保留这些消息所明确的实际医嘱或计划，不保留对话原句。
- 区分记录首行的时间、临床事件发生时间与消息发送时间。首行仍按真实记录时间；正文通常用“午后、晚间、昨夜”等有依据的时段，跨日注明日期。仅在病情骤变、抢救、重要给药或输注、不良反应、关键复测等需要准确先后关系时保留时分。消息时间并非事件时间，不能把13:17发出的报告写成13:17发生症状。原始时间在整理时用于核对，不需要默认另附时间流水账。
- 不在正文逐句追加“未见记录”。影响临床完整性的缺失集中放在正文后的“待补充／核实”，每个问题合并一次；缺少最高体温时写已记录的体温值，不一边写发热一边添加无意义的“最高值未知”。缺少治疗原因和评估不能由模型补出。
- 客观资料保留有临床意义的项目及准确统计范围。已提供的相关事实在整理核对时均纳入，但正文可以归并重复消息、精简一般交接细节，不等于逐条转录。累计汇总覆盖同一时段的单次事件时不重复相加；不能确认包含关系时只写可靠汇总，并把差异置于核实项。
- 出入量仅在来源明确累计时段时称“24小时”。存在尿便混合时分别保留原报告数值及混合限制，不计算貌似精确的总出量或液体平衡。无法解释的疼痛评分、治疗日数或简称移至核实项，不直接插入正文的括号说明。
- 不用“查房后指示”“生命体征平稳”“继续原治疗”等套话填补缺失评估。只有护理摘要时可在正文外一次说明来源；必要的观察归属仍在正文写明。简洁不意味着把拟行治疗改成已执行。

虚构行为验证：午后消息报告发热，晚间有较低体温且无退热执行信息时，描述两次实测值及变化，不写“退热药有效”；先报告一次呕吐、晚间明确为日累计两次时写两次，不累计三次；对某药回复“稍后开”时只整理为拟开具，执行状态列核实项。以上均不使用实际病例作为技能示例。

交付前按事实逐句回查：患者与日期一致、数值单位无误、异常已有评估及处理或明确待补充、变更有理由或标明缺失、输血状态与评价完整、重要沟通无虚构、无复制来的旧医嘱、无占位符及模板残句。能据现有事实改正的措辞和结构直接改好，不把编辑任务留给医生。

缺项按当前事件提出具体问题，例如“本次血小板输注的实际数量、完成时间及输后观察”，不要向每床重复索要不相关的全套资料。用户补充后整合重出完整正文，不只给追加片段。缺少必要临床资料时明确尚需补充；资料齐备也只称“供医生审核”，不能保证已通过医院质控或完全无需修改。

核对场景：只有备血信息不写已输血；异常检验无解释不补诊断；拟停药不写已停；明确查房意见保留真实归属；无查体不复制正常模板；跨午夜及换床不混合；纯格式完善不添加新的诊疗建议。
